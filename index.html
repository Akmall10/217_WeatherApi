Langkah Mengambil Screenshot Postman untuk Tugas:

  1. Buka aplikasi Postman di laptop kamu.
  2. Pilih method GET.
  3. Masukkan URL API Geocoding:
    https://api.maptiler.com/geocoding/Kebayoran%20Baru.json?key=YOUR_KEY&language=id
  4. Klik tombol Send.
  5. Pastikan respons berstatus 200 OK dan menampilkan data place_name, context (negara, provinsi, kecamatan), dan geometry.coordinates (longitude, latitude).
  6. Ambil Screenshot layar Postman dan simpan sebagai postman_screenshot.png untuk dimasukkan ke README.md.
